# Portafolio profesional — Omar Lara

## Estructura
- `index.html`: contenido y estructura.
- `assets/css/styles.css`: estilos y diseño responsive.
- `assets/js/main.js`: menú móvil, animaciones y año automático.

La sección **Habilidades** integra conocimientos técnicos y capacidades de trabajo, sin separarlos en categorías de habilidades técnicas o blandas. Los logotipos tecnológicos se cargan desde Devicon CDN, por lo que requieren conexión a internet.

## Instalación
1. Descomprime el ZIP.
2. Copia `index.html` y la carpeta `assets` a la raíz de tu repositorio `OmarLara25.github.io`.
3. Respalda tus archivos anteriores antes de reemplazarlos.
4. Abre `index.html` en IntelliJ IDEA y revisa la vista previa.

## Antes de publicar
- Confirma que las descripciones profesionales sean correctas.
- No agregues código, capturas, datos, nombres de clientes ni reglas internas de la empresa.
- El enlace de GitHub apunta al perfil `OmarLara25`. Puedes agregar enlaces directos a repositorios académicos públicos cuando los selecciones.
- Añade tus enlaces reales de LinkedIn y correo si deseas mostrarlos.

No requiere frameworks ni dependencias externas.

## Proyecto profesional destacado
- **Sistema de Vacaciones:** se presenta como proyecto principal con una descripción general y tecnologías utilizadas (Java, Spring Boot, React y SQL Server).
